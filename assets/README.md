# 素材放置说明
1. 把图片/视频放进对应文件夹:assets/<slug>/(slug:ifa-2026、project-eternal、a1-launch、es-roadshow、huion-mucha、slate-ibis-paint)。
2. 在 app.js 顶部的 MEDIA 中填路径,例如 hero:'assets/ifa-2026/hero.jpg'。
3. evidence 三项的顺序对应每个案例的 evidence 标签(见 MEDIA 注释)。留空即隐藏。支持 jpg/png/webp/mp4/webm。
建议:横图 16:9 或 4:3,宽 ≥1600px,单张 < 500KB(webp 最佳)。
